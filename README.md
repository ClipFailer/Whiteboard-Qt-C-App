# WhiteboardQt 🎨

**WhiteboardQt** — легковесное, быстрое настольное приложение виртуальной интерактивной доски в стиле **Excalidraw**, созданное на **C++20** и **Qt 6**. 

Приложение сочетает удобство бесконечного векторного холста с эстетикой рукописного скетча (hand-drawn / sketchy), позволяя быстро визуализировать идеи, проектировать архитектуру, создавать схемы и вести заметки.

---

## 🌟 Основные возможности

### 🖌️ Скетчевый рендеринг (Hand-drawn Style)
* Собственная реализация алгоритмов скетчевой отрисовки (по аналогии с Rough.js): джиттер контуров, сдвоенные штрихи Безье и процедурная штриховка.
* Регулировка шероховатости линий (`roughness` от 0 — идеальная геометрия, до 3 — выразительный чертёж от руки).
* Несколько стилей заливки: без заливки, сплошная, штриховка (hachure) и перекрёстная штриховка (cross-hachure).

### 📐 Инструменты и фигуры
* **Выделение и трансформация (`V` / `1`)**: перемещение, множественный выбор рамкой, изменение размеров за 8 маркеров с фиксацией опорной точки.
* **Панорамирование (`H` / Пробел + ЛКМ)**: свободное перемещение по бесконечному холсту.
* **Фигуры**:
  * Прямоугольники (`R` / `2`)
  * Ромбы / блоки условий (`D` / `3`)
  * Эллипсы и окружности (`O` / `4`)
  * Стрелки (`A` / `5`) и прямые линии (`L` / `6`)
* **Карандаш / Свободное рисование (`P` / `7`)**: штрихи от руки со сглаживанием кривыми Катмулла-Рома и децимацией расстояния для высокой плавности.
* **Текст (`T` / `8`)**: рукописный шрифт, перенос строк и **динамическое масштабирование размера шрифта при растяжении за маркеры**.
* **Стикеры (Sticky Notes)**: цветные карточки для заметок и брейншторминга.
* **Изображения**: вставка PNG, JPEG, WebP, BMP, GIF с сохранением пропорций при масштабировании.
* **Ластик (`E` / `0`)**: быстрое стирание объектов по траектории курсора.

### 📋 Работа с буфером обмена и файлами
* **Вставка из буфера (`Ctrl+V`)**: мгновенная вставка скриншотов или скопированного текста прямо на холст.
* **Перетаскивание (Drag & Drop)**: перетаскивание файлов картинок из проводника Windows прямо на доску.
* **Копирование как PNG (`Ctrl+Shift+C`)**: рендеринг выделенных элементов (или всей сцены) прямо в буфер обмена с прозрачным фоном.
* **Вставка из файла (`Ctrl+I`)**: выбор изображения через системный диалог.

### 🗂️ Организация и выравнивание объектов
* **Группировка (`Ctrl+G`)** и **разгруппировка (`Ctrl+Shift+G`)**: совместное выделение и перемещение связанных фигур.
* **Блокировка (`Ctrl+L`)**: защита фоновых элементов и диаграмм от случайных сдвигов и удаления.
* **Выравнивание и распределение**:
  * По левому краю, по горизонтальному центру, по правому краю
  * По верхнему краю, по вертикальному центру, по нижнему краю
  * Равномерное распределение промежутков по горизонтали и вертикали
* **Управление слоями**: перемещение на передний (`Ctrl+]`) и на задний план (`Ctrl+[`).
* **Дублирование (`Ctrl+D`)**: быстрое клонирование выделенных объектов со смещением.

### 🎨 Интерфейс и холст
* Бесконечный холст с адаптивной точечной координатной сеткой.
* Плавное масштабирование колесом мыши (`Ctrl + Колесо`) от 10% до 1000%, сброс к 100% (`Ctrl+0`) и зум по содержимому (`Shift+1`).
* Полноценная светлая и тёмная темы оформления интерфейса и холста.
* Компактная плавающая панель инструментов и боковая панель свойств элементов.
* Полная поддержка истории изменений **Undo / Redo** (`Ctrl+Z` / `Ctrl+Y`).

### 💾 Сохранение и экспорт
* **Проекты `.whiteboard`**: компактный JSON-формат, сохраняющий геометрию, стили, z-индексы и внедрённые изображения (Base64).
* **Экспорт в PNG (`Ctrl+E`)**: качественный растровый экспорт с автоматическим кадрированием по границам фигур.
* **Экспорт в SVG**: экспорт в векторный формат SVG.

## 🏗️ Архитектура проекта

```
Whiteboard/
├── CMakeLists.txt          # Сборочный конфигуратор CMake
├── main.cpp                # Точка входа в приложение
└── src/
    ├── canvas/             # Сцена и отображение холста
    │   ├── CanvasScene.*   # Обработка событий мыши, выделение, выравнивание
    │   └── CanvasView.*    # Виджет QGraphicsView, зум, панорамирование, drag & drop
    ├── commands/           # Команды паттерна Command (QUndoCommand)
    │   ├── AddItemCommand.*
    │   ├── RemoveItemCommand.*
    │   ├── MoveItemCommand.*
    │   ├── ChangePropertyCommand.*
    │   ├── GroupCommand.*
    │   └── ToggleLockCommand.*
    ├── core/               # Ядро документа и настройки
    │   ├── AppSettings.*   # Сохранение темы, сетки и геометрии окна
    │   └── Document.*      # Сериализация JSON, экспорт PNG/SVG, рендеринг в QImage
    ├── items/              # Графические элементы доски (наследники BaseItem)
    │   ├── BaseItem.*      # Базовый класс: маркеры, стили, блокировка, группы
    │   ├── RectangleItem.* # Прямоугольник
    │   ├── EllipseItem.*   # Эллипс
    │   ├── DiamondItem.*   # Ромб
    │   ├── LineItem.*      # Отрезок
    │   ├── ArrowItem.*     # Стрелка с наконечником
    │   ├── FreehandItem.*  # Плавные штрихи от руки
    │   ├── TextItem.*      # Текст с масштабированием шрифта при ресайзе
    │   ├── ImageItem.*     # Изображения с сохранением пропорций
    │   └── StickyNoteItem.*# Карточки-стикеры
    ├── renderer/           # Процедурная графика
    │   └── RoughRenderer.* # Генератор кривых Безье, джиттера и штриховки
    ├── tools/              # Инструменты
    │   └── ToolManager.*   # Состояние текущего инструмента и свойств по умолчанию
    └── ui/                 # Пользовательский интерфейс
        ├── MainWindow.*    # Главное окно, меню, горячие клавиши, строка состояния
        ├── Toolbar.*       # Панель переключения инструментов
        └── PropertiesPanel.*# Боковая панель настройки цветов, обводки, прозрачности
```

## 🛠️ Сборка и запуск

### Требования
* Компилятор с поддержкой **C++20** (GCC 12+, Clang 15+, MSVC 2022+ или MinGW 13+)
* **Qt 6.5** или выше (компоненты `Core`, `Widgets`, `Svg`)
* **CMake 3.19+**
* Система сборки **Ninja** или **Make**

### Сборка через терминал (CMake)

```bash
# Клонирование репозитория
git clone https://github.com/ClipFailer/Whiteboard-Qt-C-App.git
cd Whiteboard-Qt-C-App

# Создание каталога сборки
mkdir build && cd build

# Конфигурация проекта (укажите путь к Qt при необходимости)
cmake .. -DCMAKE_BUILD_TYPE=Release

# Сборка проекта
cmake --build .
```

### Запуск через Qt Creator
1. Откройте `CMakeLists.txt` в Qt Creator.
2. Выберите установленный комплект Qt 6 (например, `Desktop Qt 6.8.0 MinGW 64-bit`).
3. Нажмите кнопку **Собрать и запустить** (`Ctrl+R`).
